- FUSEP 태아 초음파 4,017장: train 2,408 / val 403 / calibration 403 / test 803

## 해석

- 측뇌실이 머리보다 전반적으로 어렵습니다 (작은 구조).
- 상위 모델 간 차이(DINO vs DDQ 0.39 AP)는 한 번의 seed로 우열을 확정할 수 없습니다.
- SAHI 급락 원인은 아직 규명하지 않았습니다. 좌표 복원과 병합 과정을 점검할 예정입니다.
